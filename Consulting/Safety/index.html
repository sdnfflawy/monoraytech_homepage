안전관리 시스템 _ SAFEHADA

작업 지시부터 현장사진 확인까지

운영 PC에서 작업정보를 지시하면 기사가 안전관리 앱에서 안전지침을 확인한 뒤, 카메라로 촬영한 설치 영상을 영상서버에 전송합니다. 관리자는 웹에서 사진을 보며 작업 여부와 안전 여부를 판단합니다.

운영 프로세스

관리자가 작업을 지시하고 기사의 안전수칙 준수와 설치 완료까지 확인하는 운영관리 흐름입니다. 기사 정보는 앱 로그인 시 활용됩니다.

  1. 작업정보 UPLOAD운영관리 시스템
  2. 작업지시운영관리 시스템
  3. 기사 상태확인안전수칙 준수 여부
  4. 문제 확인 시 기사 연락
  5. 설치 완료 상태 확인
  6. 모니터링

에어컨 안전점검 프로세스

작업지시를 받은 기사가 안전수칙을 안내받고 현장을 촬영하면, 사진이 실시간으로 전송되어 관리자가 이상 유무를 확인합니다.

  1. 작업정보 UPLOAD운영관리 시스템 · 주문번호 입력
  2. 작업지시운영관리 시스템
  3. 기사 앱 정보 수신
  4. 고객 동의앱 전자서명 · 카메라 설치
  5. 안전수칙 음성 안내
  1. 안전줄 연결 사진촬영기사 앱에서 사진촬영 (옵션)
  2. 카메라 작업현장 촬영기사 앱에서 현장촬영 버튼을 누르면 촬영 시작
  3. 이미지 파일 전송실외기 작업 공정 Photo cut 실시간 전송
  4. 관리자 모니터링이상 유무 확인
  5. 완료 후 App 종료
