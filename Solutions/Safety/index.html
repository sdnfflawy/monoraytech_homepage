안전관리

위험한 작업 현장을 사진으로 확인하고 관리합니다

위험한 작업을 하는 작업자의 작업정보와 현장사진을 업로드하고, 관리자가 이를 확인·관리하는 안전관리 솔루션을 제공합니다.

작업 안전관리

관리자가 작업을 생성해 지시하면 작업자가 앱과 카메라로 현장을 촬영해 올리고, 관리자는 사진을 보며 작업 여부와 안전 여부를 판단하는 솔루션.

  1. 작업 지시
  2. 현장 촬영
  3. 사진 업로드
  4. 안전 확인
